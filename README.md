# Shipox Finance

Платформа для бухгалтерии и управляющей компании: выгружает заказы из Shipox,
хранит их у себя и отдаёт отчёты.

Два приложения в одном репозитории:

| | Где | Что делает |
|---|---|---|
| **Фронтенд** | корень репозитория | Next.js: заказы, выгрузки, дашборд |
| **Бэкенд** | [`backend/`](backend/) | NestJS: синхронизация с Shipox, база, CSV |

## Вход и роли

Система закрыта: без входа любой экран уводит на форму. При первом запуске она
же предлагает завести администратора — он потом добавляет остальных на экране
«Пользователи».

| Роль | Что видит |
|---|---|
| Администратор | всё, включая сотрудников и синхронизацию |
| Диспетчер | межгород, перевозчики, склад, курьеры |
| Кладовщик | приёмка и отправка в транзит на своём складе, курьеры |
| Бухгалтер | курьеры, тарифы, начисления, выгрузки, клиенты |
| Наблюдатель | те же экраны, но без кнопок: только смотрит |

Склад кладовщика задаётся в его учётной записи: приёмка открывается сразу на
нём, чужой не выбрать. Имя вошедшего подписывает приёмки, сканы и рейсы —
отдельной настройки устройства для этого больше нет.

## Запуск

Нужны два терминала.

```bash
# 1. Бэкенд
cd backend
cp .env.example .env        # заполнить доступы к Shipox
npm run db:dev              # локальный Postgres (или npm run db:up для Docker)
npm run db:migrate
npm run start:dev           # http://localhost:4000/api

# 2. Фронтенд
npm run dev                 # http://localhost:3000
```

Фронтенд обращается к бэкенду по адресу из `NEXT_PUBLIC_API_URL`
(`.env.local`, по умолчанию `http://localhost:4000/api`). Если бэкенд не
запущен, экраны показывают это прямо на месте таблицы, а не пустой список.

Документация API: <http://localhost:4000/api/docs>

## Экраны

| Путь | Что показывает |
|---|---|
| `/dashboard` | Заказы за период по статусам, состояние базы и синхронизации |
| `/orders` | Реестр заказов с фильтрами по клиенту, городу, статусу и поиском |
| `/orders/[номер]` | Карточка заказа, включая сырой ответ Shipox |
| `/exports` | Готовые CSV: скачать или сформировать вручную |

## Ветка `/demo`

Экраны тарификатора, начислений курьерам, дебиторки и разбивки заказа на плечи
лежат в [`src/app/demo/`](src/app/demo/) и работают на демо-данных. В меню их
нет: под них у бэкенда пока нет данных — Shipox не отдаёт исполнителей по
участкам доставки. Показывать вымышленные цифры рядом с настоящими нельзя,
поэтому экраны скрыты, но код, движок тарификации и финансовые расчёты
сохранены и покрыты тестами.

Вернутся в меню, когда появятся данные по исполнителям.

```bash
npm test          # тесты фронтенда
npm run build

cd backend
npm test          # разбор ответа Shipox, формат CSV, границы суток
npm run test:e2e  # выгрузка обновляет базу, файл совпадает с форматом Shipox
```
